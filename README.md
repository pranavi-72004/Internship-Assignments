# Cybersecurity & Ethical Hacking Internship Projects

## Overview

This repository contains cybersecurity projects and assignments completed during a Cybersecurity and Ethical Hacking Internship. The projects focus on network security, vulnerability assessment, web security, cryptography, traffic analysis, and security monitoring using Python and industry-standard security concepts.

The objective of these projects is to gain practical experience in identifying, analyzing, and mitigating security threats while strengthening foundational cybersecurity skills.

---

## Projects Included

### 1. Password Strength Analyzer
A Python-based tool that evaluates password strength based on security parameters such as length, uppercase letters, lowercase letters, numbers, and special characters.

**Features**
- Password strength assessment
- Security recommendations
- Weak, Medium, and Strong classification

### 2. Port Scanner
A network scanning tool that identifies open ports and active services on a target system.

**Features**
- TCP port scanning
- Open port detection
- Basic network reconnaissance

### 3. Phishing URL Detector
A rule-based system that analyzes URLs and identifies potential phishing attempts using common indicators.

**Features**
- URL analysis
- Suspicious keyword detection
- Risk-level classification

### 4. Network Packet Analyzer
A network traffic monitoring tool developed using Scapy to capture and analyze packets in real time.

**Features**
- Packet capture
- Source and destination IP analysis
- Protocol identification

### 5. Vulnerability Assessment Dashboard
A web-based dashboard for displaying and analyzing vulnerability scan results.

**Features**
- Vulnerability categorization
- Severity-based reporting
- Security recommendations

### 6. File Integrity Monitor
A file monitoring system that detects unauthorized modifications using cryptographic hash functions.

**Features**
- SHA-256 hashing
- Integrity verification
- Change detection

### 7. Security Log Monitor
A log analysis tool that identifies suspicious activities and generates security reports.

**Features**
- Failed login detection
- IP activity tracking
- Report generation

### 8. Website Security Scanner
A basic web security assessment tool that checks websites for security best practices.

**Features**
- HTTPS verification
- Security header analysis
- Security assessment reporting

### 9. Network Monitoring Tool
A real-time network monitoring application that tracks network usage statistics.

**Features**
- Bandwidth monitoring
- Data transmission tracking
- Network activity visualization
